One line, 115 characters, roasting the gadget I use every day — my wireless earbuds:

> My earbuds pair with my neighbour's TV faster than with my own phone, and honestly, the neighbour has better taste.

`main.py` writes that line to `/output/entry.txt` (the file the make.fun judge reads). It self-checks the competition gate first: the line must be 1–200 characters and not only whitespace, or the program exits without writing anything.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
